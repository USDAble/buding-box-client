## 阶段总结规则

每个阶段的全部退出条件满足后，在该阶段目录新增 `阶段总结.md`。总结必须记录：

1. 实际完成的任务和用户可见结果。
2. 对应分支、提交和合入点。
3. 先红后绿与变异验证证据。
4. 自动化、手工验收及门禁结果。
5. 实际改动与原计划的偏差。
6. 未完成项、外部阻塞和下一阶段输入。
7. canonical 文档的同步情况。

不得在阶段结束前创建带“已完成”结论的总结；进行中的证据写入阶段 `README.md` 的执行记录区。
