# backend 抽象层与中台对接

> 本文件夹是从 `../问题盘点.md` 拆出的**第一批优先开发任务**，聚焦「架构问题」与「mock 接口问题」。
>
> **边界澄清**：`internal/backend`、`backend/local` 以及未来的 `backend/remote` 都是当前客户端仓库内的产品服务端口和 HTTP 客户端适配器；它们不是中台服务。中台模型网关、控制面、账本、数据库、密钥管理和部署不在此仓库开发。`中台交付包.md` 是给外部同事的合同和验收要求，不是本仓库的服务端待办。
>
> **现状澄清**：当前代码库只有 `internal/server`；`internal/backend` 和 `internal/productapp` 尚不存在，均是 P0 新建的客户端包。产品约束以 [P0 正式上线需求基线](../P0-正式上线需求基线.md) 为准，开发顺序以 [P0 开发顺序与协作计划](../P0-正式服务与Agent演进/P0-开发顺序与协作计划.md) 为准。

## 当前仓库执行顺序

```
B0 接口定义 ──► B1 本地实现 + server 改造 ──► B2 模型目录 ──► B3 词源留位
B0 接口定义 ──► B3 词源留位
B4 失败关修复（已完成，不阻塞上述链路）
```

B0（端口、DTO、错误语义）是所有 P0 的首个合并关卡，必须先合入；B1 合入后，当前仓库接中台（盘点 D 类）只剩「新增 `backend/remote` 客户端适配器 + 改一处装配」，UI / agent / server handler 均不动。中台服务端则由其团队依据 `中台交付包.md` 在独立仓库并行实现。
