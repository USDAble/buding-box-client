## 4. 兼容性与跨平台审计

- 物理 CPU 为 AMD Ryzen 9 5900X，Windows 为 64 位；PATH 原先命中 `windows/386` Go，而非硬件限制。
- Wails/WebView2 在错误命中的 32 位工具链初始化 Windows callback 时会触发 `compileCallback: argument size is larger than uintptr`。官方 x64 Go 已安装，并已通过绝对路径完成 Desktop 测试和构建；系统 PATH 的旧 x86 项仍需管理员一次性清理。仓库代码、脚本和 CI 没有写死 `GOARCH=amd64`。
- `icon.icns` 已通过跨平台生成器替换为新临时图标，但仍需 macOS CI/真机验证 Finder、Dock 和托盘实际显示。
- Windows 安装器源已从弃用的 `FileCopy` API 改为 `CopyFile`，重新编译后无该弃用提示。
- Windows 上的构建与安装器编译不等于 macOS/Linux/AppImage 或 Android/iOS 的运行时验收。
