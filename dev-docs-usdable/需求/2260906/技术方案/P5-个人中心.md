## 1 结论

1. **个人中心是一个新界面，不是设置弹窗的改造。** 它承担的是"账号 / 套餐 / 积分 / 授权 / 设置入口 / 帮助 / 关于"这一组**产品态**信息，与上游"完整设置"（模型、权限、端点）职责不同。混成一个界面会让上游设置页每次改动都撞上产品态。
2. **一个界面两列**：左侧导航、右侧内容；点击遮罩或 Esc 关闭。
3. **左下角是唯一入口**，并且它本身就是"登录态显示器"（头像 + 昵称 + 积分），不是原来那个"设置 + 版本号"。

## 2 结构

### 2.1 左下角（`AccountCorner.svelte`）

替换原「设置 + 版本号」：

| 元素 | 内容 |
| --- | --- |
| 头像 | 昵称首字（本期不上传头像） |
| 昵称 | 超过约 8 个汉字省略（见 §4.1） |
| 次行 | `积分 {整数}` |
| 点击行为 | 打开个人中心 |
| 原「设置」入口 | **移进个人中心**，不得丢失 |

**窄侧栏（rail）时只显示头像**，点击行为不变。积分**不显示** —— 位置不够时的取舍，宁可少显示也不换行挤压会话列表。

### 2.2 面板布局（`AccountPanel.svelte`）

从**右侧滑出**，宽度约覆盖主区右侧三分之一；左侧导航、右侧内容；**点击遮罩或按 Esc 关闭**。

锚点定位（`anchorEl` + `fixedWidth`）每一帧从触发元素的 `rect` 重算，所以面板开着时拖侧栏分隔条或改窗口大小都能跟随，不需要给每个尺寸变化源接线。

### 2.3 导航与内容

| 导航 | 内容 |
| --- | --- |
| 账号 | 默认头像、昵称（可改，规则同登录页、含敏感词校验；保存后左下角立刻变）、脱敏手机号 |
| 套餐版本 | 套餐名（本期假数据「体验版」）；「升级」打开占位页，无支付 |
| 积分 | 余额与本月消耗（来源见 `需求基线 E9`） |
| 授权 | 见 §5 |
| 设置 | 语言中/英（立即生效，与拦截页同一份设置）；新会话默认模式（隐私/智能/默认，**出厂「默认」**）；主题与字号跳转完整设置；便携包**不展示**开机自启动 |
| 帮助与反馈 | 占位或外链；演示说明可写测试验证码/激活码 |
| 检查更新 | 仅此一处，占位「即将支持」。**无托盘更新、无后台自动检查** |
| 关于 | 版本号、用户协议、隐私政策、版权行 |

**「退出登录」固定在侧栏底部**，不占上述导航项（它是会话级动作，不是"个人中心的一个页面"）。

**为什么激活状态与盒子编号走本地缓存：** 授权页要**离线可读** —— 目录不可达、断网时用户也应该能查到自己的授权信息。这类信息在首次激活时已写入数据根，不需要每次联网取。

## 4 交互规则

### 4.1 昵称省略

按**宽度**省略，不按字符数截断。

理由：中英混排按字数截会切得很难看（`Alexandria` 与 `张三` 同样占 8 个"字符"，视觉宽度差三倍）。CSS `text-overflow: ellipsis` + `max-width` 让浏览器按真实度量决定截断点。

昵称可改，规则与登录页一致（长度 + 格式 + **敏感词校验**，命中则拒绝保存）。保存成功后左下角**立刻**变化，不需要刷新。

### 4.2 Esc 的归属（`globalKeys.ts`）

`dismissIntent()` 只回答**无修饰键的 Esc**，返回 `'overlay'`。

**刻意不并入 `globalKeyIntent()`：** 那个函数只处理**带修饰键**的快捷键（⌘K / ⌘N）。Esc 不带修饰键，它的归属权必须留给真正的模态 —— 命令面板、设置弹窗、确认框都自带 Esc 语义。个人中心是**非模态**面板，不能抢走它们的键。

因此：`dismissIntent()` 只声明"这个 Esc 是关闭覆盖层的意图"，**由调用方决定当前是否适用**。面板开着时关闭面板；模态开着时模态先拿到它。

### 4.3 面板状态与页面栈（`stores.ts`）

一个 store 承担两件事：

```ts
export const accountPanelOpen = writable(false)
export const accountPanelPage = writable<AccountPanelPage>('root')
```

`accountPanelPage` 同时表示**层级**（`'root'` 就是导航列表本身）与**当前二级页** —— 一个 store 而不是两个，因为面板是**原地切换**的（像手机设置的逐级下钻），"开着且在第 N 层"是一个状态而不是两个独立状态。

**每次打开都重置为 `'root'`。** 理由：重新打开却停在上次看的那一页，会让"点左下角"这个动作的结果不确定 —— 用户想进的通常是导航列表。

页面取值：`root | plan | credits | license | settings | sensitive | help | about`。

### 4.4 与"完整设置"的关系

本面板的「设置」页只保留**产品态**设置（语言、新会话默认模式、主题/字号的跳转），并提供一个「打开完整设置」入口。

**边界.** 模型 / 权限 / 端点等仍用上游设置弹窗。跳转通过 `openSettingsAt(cat, subView?)` 携带一个一次性的 `settingsTarget`，弹窗消费后清空 —— 所以"从个人中心跳过去"能落到正确分类，而之后单独打开设置不会卡在上次的目标上。

### 4.5 退出登录

固定在侧栏底部。行为见 `需求基线 E7`；本轮**不**清刷新令牌的例外见 `V-16`（归 `PR-2c`）。

## 5 授权页（`E5`）

能进入个人中心即说明**这份数据根已完成激活**（未激活进不了主界面）。

**规则.**

1. 状态只有「已激活」或「已过期」，**不出现「未激活」空态**。
2. 剩余天数 = `max(0, 到期日 − 今天)`（本机本地日历）。
3. 展示：剩余天数 + 绑定脱敏手机号 + **盒子编号（不脱敏）**。
4. **不展示 U 盘激活码**（一次性凭证，本地状态里也没有它）。
5. **不显示「绑定于当前程序目录」**（见 §7 第 1 条）。
6. 盒子编号读 `productState.activation.boxCode`；**老数据缺该字段时显示「—」**，不拦截、不要求补填。
7. 本期**到期不拦截**：显示「已过期」、剩余 0 天，仍可对话。

## 6 验收

| # | 验收项 | 判据 |
| --- | --- | --- |
| 1 | 入口唯一 | 只有左下角能打开个人中心；原「设置」入口在面板内可见 |
| 2 | rail 形态 | 窄侧栏只显示头像，点击仍能打开 |
| 3 | Esc 不抢模态 | 设置弹窗开着时按 Esc → 关设置；个人中心开着时按 Esc → 关面板 |
| 4 | 打开必回导航 | 进到「关于」→ 关闭 → 重新打开 → 停在导航列表 |
| 5 | 昵称省略按宽度 | 长英文名与长中文名都不会硬切字符 |
| 6 | 昵称即时生效 | 改昵称保存 → 左下角立刻变 |
| 7 | 授权页无空态 | 任何可达状态下都不出现「未激活」 |
| 8 | 盒子编号不脱敏 | 授权页原文显示；缺字段显示「—」且不拦截 |
| 9 | 无「绑定于当前程序目录」 | 界面与文案表里都搜不到该串 |
| 10 | 跳转一次性 | 从个人中心跳设置 → 落在目标分类；再单独开设置 → 落在默认分类 |
