## 文档约定

1. 一个主题只保留四类现行文档：**实施计划与阶段状态**、**同步与修改指南**、**本地编译、打包与人工验收手册**、**最终审计报告**。
2. 新主题先建立子目录，再在本 README 增加索引；长期设计应并入实施计划的“未来预留”，不要拆成多份重叠文档。
3. 涉及代码、CI、安装器、资料源或兼容性时，必须同步更新阶段状态、验收手册和审计报告。
4. 不得通过删除许可证、真实版权或第三方归属来伪造开发主体。
