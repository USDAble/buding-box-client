# 布丁盒子品牌同步与修改指南

- **主配置：** `E:\zxy\work-code\buding-box-client\branding\brand.json`
- **同步命令：** `node scripts/sync-branding.mjs`
- **只读检查：** `node scripts/sync-branding.mjs --check`
- **最后更新：** 2026-09-03

## 1. 唯一可编辑资料源

日后修改产品名、团队资料、链接、文案、色板或临时标识状态时，只编辑：

```text
branding/brand.json
```

常用字段：

| 需求 | 字段 |
|---|---|
| 中文/英文产品名 | `product.names.zh-CN`、`product.names.en-US` |
| 其他语言名称 | `product.names.zh-TW`、`ja-JP`、`ko-KR`、`es-ES`、`fr-FR` |
| 定位、标语、长描述 | `product.category`、`product.tagline`、`product.description` |
| 欢迎页、设置、About 等短文案 | `copy.*` |
| 团队、版权、联系邮箱 | `about.*` |
| 官网、文档、下载、隐私、反馈链接 | `links.*` |
| 色板与临时 Logo 标记 | `visual.colors`、`visual.logo.temporary` |

`.example` 域名、`<your-org>` 和当前团队主体均为 Mock；正式资料到位后在此处替换。不要删除许可证、真实版权或第三方归属。

## 2. 同步目标：禁止手改

运行同步器会从主配置生成下列文件。它们必须提交到仓库，以便不运行 Node 的构建也能读取一致资料；但**不得直接编辑**：

```text
internal/brand/brand.json
web/src/lib/brand.config.json
mobile/src/brand.config.json
landing/brand.config.json
cmd/octo-relay/internal/push/brand.json
web/public/favicon.svg
landing/pudding-box-mark.svg
packaging/windows/brand.iss
```

其中 `packaging/windows/brand.iss` 向 Inno Setup 提供产品英文名、发布主体和官网宏。`packaging/windows/octo.iss` 只引用这些宏，因此以后改安装器产品名称或发布者也只需改主配置并同步。

每次修改后的固定流程：

```powershell
Set-Location E:\zxy\work-code\buding-box-client
node scripts/sync-branding.mjs
node scripts/sync-branding.mjs --check
node --test scripts/sync-branding.test.mjs scripts/brand-ci.test.mjs
```

`--check` 不会写任何文件；它发现副本缺失或漂移时会以非零状态退出，CI 也会拦截。

## 3. 替换正式 1024×1024 PNG Logo（跨平台资产生成器）

输入必须是**可解码、精确 1024×1024 的 PNG**。处理全部 Logo 派生资产的唯一工具已存在于 `E:\zxy\work-code\buding-box-client\cmd\generate-brand-assets\main.go`；它不依赖 macOS `iconutil`、ImageMagick、Python 或其他外部图像软件。不要另行手改或另建重复的图标脚本。

```powershell
Set-Location E:\zxy\work-code\buding-box-client
pwsh .\scripts\update-brand-assets.ps1 -InputPath "C:\path\to\pudding-box-logo-1024.png"
```

日常只使用这个统一入口；它会调用底层 Go 生成器、同步品牌副本、执行 `--check` 和品牌测试。底层 `cmd\generate-brand-assets` 仅作为实现，不建议手动逐个运行或替换 ICO、ICNS、PNG、SVG。

如果当前 `go` 仍是 `windows/386`，请按验收手册改用与构建机相匹配的官方 64 位 Go（x64 Windows 用 amd64 Go，ARM64 Windows 用 arm64 Go）再运行以上命令；不要在仓库中设置 `GOARCH=amd64`。

生成器会写入：

```text
branding/assets/pudding-box-icon-{1024,512,256,192,180,152,144,128,120,96,72,64,48,32,16}.png
branding/assets/pudding-box-mark.svg
cmd/octo-desktop/build/windows/icon.ico
cmd/octo-desktop/build/linux/icon.png
cmd/octo-desktop/build/darwin/tray-icon.png
cmd/octo-desktop/build/darwin/icon.icns
```

确认视觉与商标授权无误后，把 `branding/brand.json` 的 `visual.logo.temporary` 改为 `false`，再同步、测试和重新打包。

## 4. 禁止在本 PR 迁移的技术身份

```text

OCTO_
octo-ui
octo-pair
```
