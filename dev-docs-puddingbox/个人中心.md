# 个人中心

写作参照：`dev-docs/desktop-update-notice.md`

> 个人中心从侧栏底部的账户角进入，在同一面板中展示账户、积分、授权与少量产品偏好；它不是完整设置页的副本，也不拥有产品状态的第二份缓存。

## 范围

本文件定义入口、面板层级、账户与偏好的呈现、退出登录和授权信息。账户字段与写入接口由 `本地API契约.md` 定义，登录与退出语义由 `登录、访问控制与拦截页.md` 定义，词库编辑由 `词库管理.md` 定义。

## 非目标

- 不在个人中心显示或编辑中台 token、激活码或原始手机号。
- 不把完整设置页的通用偏好复制成第二套表单。
- 不在前端自行计算或乐观修改余额。

## 入口与层级

已登录且状态带昵称时，账户入口固定在侧栏底部；窄侧栏只显示头像，常规侧栏显示昵称和当前积分。点击后打开一个与侧栏同宽、从底部升起的非模态账户面板。它 portal 到页面根，避免被侧栏的收缩布局裁剪；面板仍以账户角为锚点，重复点击该角可收起。

根页包含套餐、积分、授权、设置、词库、帮助、检查更新和关于入口。检查更新当前明确显示为不可用；充值能力和更新能力都不能伪装为可执行流程。二级页在同一面板内替换，返回回到根页；关闭、面板外点击与 Esc 只关闭该面板，不应同时关闭主窗口或打断聊天输入。每次重新打开都回到根页，不持久化“是否打开”或上一次的二级页。

## 账户信息与昵称

根页展示昵称、积分、套餐和授权摘要；设置页可编辑昵称与语言。当前账户面板不展示手机号，授权页也不重现激活凭证。缺少可选字段使用明确占位，不根据本地猜测补造值。

昵称编辑提交后以服务端返回的 `ProductStateDTO` 覆盖共享状态；前端预检只改善即时反馈，服务端归一化和拒绝结果才是事实。昵称的格式与敏感词错误必须按本地 API 契约显示，不能把业务级错误塞进输入框信封。

## 偏好与完整设置

个人中心只提供语言等账户级偏好，不再提供“隐私 / 智能 / 普通”默认模式。个人信息保护和私密会话是新会话在输入区选择并在首条消息后锁定的会话边界；内容安全输入检查也从输入区的“安全与隐私”面板调整。词库管理继续作为个人中心的独立二级页。

语言变化先切换统一本地化状态，再持久化到产品状态；持久化失败会提示，下一次启动恢复已保存的语言。旧三组默认模式控件和偏好已经删除，且未迁移成私密会话默认值，因为旧 `privacy` 没有真正提供相应安全保证。详见 [个人信息保护与私密会话](个人信息保护与私密会话.md) 和 [模型选择与私密会话](模型选择与私密会话.md)。

## 余额与充值

余额只显示服务器账本刷新后的 `credits.balance`。任何“余额可能变化”的事件只触发刷新，不携带或本地增减数值。根页和积分二级页都消费这同一状态投影。

充值入口可以常驻，但必须给出当前可执行动作；尚未提供的能力应明确为不可用，不跳转到空白页或无效地址。

## 退出登录与授权页

退出入口调用统一登出流程。它清除凭证并回到拦截页，但保留绑定账号和激活记录；平台撤销失败应如实反映，不阻止本地退出。

授权信息是只读说明，不能把一次性激活凭证重新展示给用户。需要重新激活或支持时，交由登录/拦截页的明确流程处理。

## 验证

- 账户入口、打开/关闭/返回、面板外点击和 Esc 的层级行为一致，重开从根页开始。
- 昵称与偏好写入后，所有消费方读取同一份返回状态；昵称格式与敏感词拒绝显示不同的业务结果。
- 余额不会由前端本地计算或 WebSocket 载荷覆盖；没有可用充值或更新流程时展示不可用状态。
- 退出后个人中心不可继续显示已登录数据，重开窗口进入产品门。
