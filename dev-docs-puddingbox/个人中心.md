# 个人中心

写作参照：`dev-docs/desktop-update-notice.md`

> 账户角从侧栏底部进入，是单层的状态概览和快捷入口；完整账户编辑、安全设置和危险操作统一在设置页完成。它不拥有产品状态的第二份缓存。

## 范围

本文件定义账户角、完整设置中的账户区、退出登录和授权信息。账户字段与写入接口由 `本地API契约.md` 定义，登录与退出语义由 `登录、访问控制与拦截页.md` 定义，安全与隐私设置由 `内容安全防护.md`、`个人信息保护与私密会话.md` 和 `词库管理.md` 定义。

## 非目标

- 不在个人中心显示或编辑中台 token、激活码或原始手机号。
- 不把完整设置页的通用偏好复制成第二套表单。
- 不在前端自行计算或乐观修改余额。

## 入口与层级

已登录且状态带昵称时，账户入口固定在侧栏底部；窄侧栏只显示头像，常规侧栏显示昵称和当前积分。点击后打开一个与侧栏同宽、从底部升起的非模态账户面板。它 portal 到页面根，避免被侧栏的收缩布局裁剪；面板仍以账户角为锚点，重复点击该角可收起。

面板只保留一个层级：顶部为昵称和脱敏手机号；紧随其后展示套餐（含升级入口）、积分（含刷新与充值入口）和授权摘要。下方快捷入口只做跳转：管理账号、`安全与隐私`、完整设置、帮助与反馈、关于；另有“检查更新”这一项唯一的即时动作。它仅在桌面壳、用户主动点击时经本地 native bridge 做一次只读版本查询，结果只提示“有新版本”或“已是最新”，不下载、不安装、不启动定时检查。关闭、面板外点击与 Esc 只关闭该面板，不应同时关闭主窗口或打断聊天输入。

没有支付地址时升级、充值明确提示“即将支持”，不伪造成功或跳转空白页。帮助与反馈入口不在账户角内再打开狭窄二级面板：它打开与完整设置同级的“帮助与反馈”完整页面；账户角只负责把用户带到那里。

## 帮助与反馈只解决用户可行动的问题

帮助页内置少量稳定的常见问题，而非复制开发文档或搭建第二个帮助中心。首版至少解释：如何选择和切换模型、个人信息自动脱敏的范围、私密会话对模型的约束、模型或网络不可用时怎样处理，以及怎样提交产品反馈。答案只给用户可执行的操作和产品边界；不公开调试 Profile、控制面地址、测试凭据或内部错误细节。

页面底部提供“访问官网”外部链接，取自 `branding/brand.json` 的 `links.external.website`，不得在 Web 代码或本地化文案中再写一个网址。该字段目前仍是品牌迁移占位值，必须先替换为真实的布丁盒子 HTTPS 官网地址，才可在用户界面启用链接；未配置真实地址时保留简短的“官网即将上线”说明，不打开上游站点或空白页。品牌字段的所有权和发布校验见 [品牌与标识](品牌与标识.md)。

同页提供反馈表单，只有 `bug`、`suggestion`、`other` 三个类别和必填正文；正文按 Unicode 字符计数，去除首尾空白后为 1–4000 个字符。发送前清楚说明“只发送你在此填写的内容”，提交成功显示回执编号；失败保留当前表单供用户自行重试，并复用同一个内存幂等键。它通过本地 `POST /api/product/feedback` 代理至控制面，浏览器永不接触平台 bearer token，完整字段、错误和数据最小化边界见 [本地 API 契约](本地API契约.md) 与 [中台接口契约](中台接口契约.md)。

产品反馈与会话中的 `FeedbackModal` 是两条完全不同的通道：后者是模型请求的即时许可回答，不能收集、代替或上传产品反馈。反馈首版不自动携带聊天内容、会话历史、附件、OCR、工具参数/返回值、模型提示词、token、手机号、原始设备标识、数据根路径或日志；也不做失败后的后台排队与自动重发。若未来确有诊断材料需求，必须单独设计用户可见的逐项选择与脱敏边界，不能在本接口悄然扩展。

## 账户信息与昵称

账户角展示昵称、积分、套餐和授权摘要；完整设置的“账号”分类可编辑昵称，显示脱敏手机号与授权到期时间。账号角不放表单、长列表或危险操作；缺少可选字段使用明确占位，不根据本地猜测补造值。一次性激活凭证永不重现。

昵称编辑提交后以服务端返回的 `ProductStateDTO` 覆盖共享状态；前端预检只改善即时反馈，服务端归一化和拒绝结果才是事实。昵称的格式与敏感词错误必须按本地 API 契约显示，不能把业务级错误塞进输入框信封。

## 偏好与完整设置

语言等通用偏好在完整设置的“常规”分类；不再提供“隐私 / 智能 / 普通”默认模式。个人信息保护和私密会话是新会话在输入区选择并在首条消息后锁定的会话边界；内容安全输入检查也从输入区的“安全与隐私”面板调整。词库管理位于完整设置的“安全与隐私”分类，与只读个人信息规则并列，不塞进账户角。

语言变化先切换统一本地化状态，再持久化到产品状态；持久化失败会提示，下一次启动恢复已保存的语言。旧三组默认模式控件和偏好已经删除，且未迁移成私密会话默认值，因为旧 `privacy` 没有真正提供相应安全保证。详见 [个人信息保护与私密会话](个人信息保护与私密会话.md) 和 [模型选择与私密会话](模型选择与私密会话.md)。

## 余额与充值

余额只显示服务器账本刷新后的 `credits.balance`。任何“余额可能变化”的事件只触发刷新，不携带或本地增减数值。根页和积分二级页都消费这同一状态投影。

充值入口可以常驻，但必须给出当前可执行动作；尚未提供的能力应明确为不可用，不跳转到空白页或无效地址。

## 退出登录与授权页

退出入口只在完整设置的“账号 → 账号安全”区域出现，并在二次确认后调用统一登出流程。它清除凭证并回到拦截页，但保留绑定账号和激活记录；平台撤销失败应如实反映，不阻止本地退出。

授权信息是只读说明，不能把一次性激活凭证重新展示给用户。需要重新激活或支持时，交由登录/拦截页的明确流程处理。

## 验证

- 账户角始终单层；打开/关闭、面板外点击和 Esc 的行为一致，快捷入口只打开目标设置分类。
- 昵称写入后，所有消费方读取同一份返回状态；昵称格式与敏感词拒绝显示不同的业务结果。
- 余额不会由前端本地计算或 WebSocket 载荷覆盖；没有可用充值、升级或反馈流程时准确显示当前不可用状态。
- 帮助与反馈从账户角进入完整页面；FAQ 不包含内部运维信息，官网地址只读品牌事实源且迁移占位值绝不对用户跳转。
- 反馈只发送类别和用户主动填写的正文；本地失败保留表单但不落盘、排队或附带聊天/诊断数据，成功只显示控制面回执编号。
- 退出不在账户角出现；从账号安全区退出后，账户角不可继续显示已登录数据，重开窗口进入产品门。
