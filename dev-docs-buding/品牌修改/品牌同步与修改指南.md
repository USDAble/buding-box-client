# 品牌同步与修改指南

## 当前状态

本轮品牌主题为“品牌修改”。公开展示名称已统一为：

- 中文：**布丁盒子**
- English：**Pudding Box**
- 默认界面语言：中文 `zh-CN`；英文 `en-US`
- Logo：当前使用临时 SVG，发布前可替换为正式素材

## 唯一修改入口

后续修改品牌资料时，优先只编辑：

```text
E:\zxy\work-code\buding-box-client\branding\brand.json
```

该文件集中管理产品名、短名、分类、Slogan、简介、About 团队名、版权主体、邮箱、链接、色板、Logo 路径、兼容标识和未来迁移候选值。

然后在仓库根目录运行：

```powershell
node scripts/sync-branding.mjs
```

同步脚本会更新以下生成文件，**不要手工修改这些副本**：

```text
internal/brand/brand.json
web/src/lib/brand.config.json
mobile/src/brand.config.json
web/public/favicon.svg
landing/pudding-box-mark.svg
landing/brand.config.json
```

Go、Web、Mobile 分别通过品牌读取层消费配置：

```text
internal/brand/brand.go
web/src/lib/brand.ts
mobile/src/brand.ts
```

## Logo 修改

临时 Logo 源文件：

```text
E:\zxy\work-code\buding-box-client\branding\assets\pudding-box-mark.svg
```

替换 Logo 时：

1. 将正式 SVG 放到 `branding/assets/`；
2. 修改 `branding/brand.json` 中 `visual.logo.mark` 和 `visual.logo.favicon`；
3. 运行同步脚本；
4. 额外检查桌面端图标资源：
   - `cmd/octo-desktop/build/darwin/icon.icns`
   - `cmd/octo-desktop/build/linux/icon.png`
   - `cmd/octo-desktop/build/windows/icon.ico`
   - Windows 资源生成入口 `cmd/octo-desktop/build/windows/generate-syso/main.go`

位图、ICNS、ICO 不是由当前 JSON 脚本自动生成的，需要在正式发布前单独替换并做各系统安装包验收。

## Mock 资料发布前必须替换

以下资料目前是开发预览用 Mock 值，不能直接当作真实运营信息发布：

```text
hello@puddingbox.example
support@puddingbox.example
security@puddingbox.example
https://puddingbox.example
https://docs.puddingbox.example
https://download.puddingbox.example
https://github.com/<your-org>/pudding-box-client
```

替换位置以 `branding/brand.json` 为主；文档中的示例和发布平台配置也要同步检查。尤其要确认邮件域名、隐私政策、反馈入口、下载地址、仓库归属和版权主体均已获得实际团队授权。

## 兼容标识不可直接替换

当前有意保留的运行时身份：

```text
octo
~/.octo
OCTO_
octo-ui
octo-pair
github.com/open-octo/octo-agent
```

这些标识关系到旧用户脚本、配置、数据目录、配对和升级。未来若要迁移到 `puddingbox`，必须先按《完整身份迁移预留方案.md》设计双读、迁移提示、回滚和升级测试，不能执行全局字符串替换。

## 每次主题修改的固定规则

- 在 `dev-docs-buding/` 下新建一个主题子目录，例如 `品牌修改/`、`发布渠道切换/`、`数据目录迁移/`；
- 一个主题一个目录，方案、实施记录、验收清单和审计报告放在同一目录；
- 每次改动都记录目标、范围、影响面、回滚方式、验证命令和未决事项；
- 保留许可证、版权、第三方归属和真实源码来源，不通过删改归属制造虚假原创；
- 完成代码后必须执行一次全仓库品牌审计，并将有意保留的兼容标识单独列出。
