# 办公文件在产物栏中提供下载

写作参照：`dev-docs/web-artifacts-panel-design.md`。

会话创建或展示的 Word（`.doc/.docx`）、Excel（`.xls/.xlsx`）、PowerPoint（`.ppt/.pptx`）文件进入产物栏，显示文件名与类型，并可下载原始字节。当前不解析文件内容，也不提供网页内预览。

## 入口与边界

`write_file`、`edit_file` 的成功结果沿用现有 `ui_payload` 自动列出文件；脚本或终端生成的文件需调用 `show_artifact`，由同一入口列出。前端 `EXT_KIND` 与后端 `artifactContentTypes` 必须包含相同扩展名。其他源码和配置文件仍不进入产物栏。

下载复用会话产物接口与现有浏览器下载、桌面原生保存流程，不增设第二条授权路径。服务端只允许读取该会话成功写入或明确展示的路径；办公文件以 `application/octet-stream` 和 `Content-Disposition: attachment` 返回。下载上限为 100 MB，超过时返回 413；HTML、Markdown、图片仍保留 10 MB 预览上限。HTML 产物的资源授权不包含邻近的办公文件。

## 非目标

- 不在应用中预览或编辑 Word、Excel、PowerPoint。
- 不自动扫描磁盘上的全部办公文件；未写入当前会话、未调用 `show_artifact` 的文件不会出现。
- 不纳入宏启用格式或 CSV；是否扩展需另行确认格式及安全边界。

## 验证

前端 `artifacts.test.ts` 检查六种扩展名只建下载条目、不读取二进制为预览；`artifact-actions.test.ts` 检查浏览器和桌面保存原始字节。Go 的 `artifact_test.go` 检查扩展名与 HTML 资源隔离；`artifact_handler_test.go` 检查下载头、跨会话拒绝和大小上限。
