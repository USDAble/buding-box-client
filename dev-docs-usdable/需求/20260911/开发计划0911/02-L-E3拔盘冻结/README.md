# 阶段 2：L-E3 拔盘冻结与恢复

## 目标

运行中程序目录消失时立即冻结界面并停止写入；同路径恢复后继续，换路径或换盘符则要求退出重开。

## 建议分支

`feat/pr-7-datastore-freeze`

## 任务

- 从归档实现按文件搬运 watchdog、冻结状态和测试，不整分支合并。
- 对齐当前 `internal/datapath`、`internal/productruntime` 和桌面壳装配方式。
- 完成目录存在、丢失、持续丢失、同路径恢复、换路径五态状态机。
- 冻结后统一拒绝会话、词库、凭证、日志等写入。
- 复用前端已有 `FrozenOverlay` 和 `frozen` store。
- `datastore:lost` / `datastore:restored` 的载荷按 `G1`，不得自行发明协议。
- 验证任何失败路径都不会回落写主机目录。

## 退出条件

- 丢失和恢复事件各只在状态跃迁时触发一次。
- 冻结期间所有业务写入被拒绝。
- 同路径恢复后可继续；新路径不被误判为恢复。
- 真机拔盘/恢复场景通过。
- `make gate` 和 `make test-production` 通过，owner 文档同步。
