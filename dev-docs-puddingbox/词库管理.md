# 词库管理

写作参照：`dev-docs/endpoint-custom-headers-design.md`

> 词库管理页让用户查看内置词和维护个人词。用户词文件是可编辑层的唯一事实源，页面只显示服务端读取和写回的结果；导入是合并，预览不写盘。

## 范围

本文件定义词库页面、用户词编辑、导入导出和可见反馈。词库在内容安全防护中的语义由 [内容安全防护](内容安全防护.md) 定义，端点形状与错误码由 [本地 API 契约](本地API契约.md) 定义。

## 非目标

- 不让用户编辑、删除或覆盖内置词。
- 不让页面拥有独立的词形归一化、去重或命中规则。
- 不把导入实现为覆盖，或把预览实现为隐式写盘。

## 页面与事实源

页面分为可展开的只读内置词和可编辑用户词两个列表。计数、空态和编辑结果都来自接口返回的实际词表；用户词文件不存在表示空列表，不是错误，也不在读取时创建文件。每次打开面板重新读取，因而可反映用户手工修改的文件。

内置词随产品交付，用户词位于数据根；已验证的服务端词是过滤引擎的另一只读层，但当前管理页不展示或编辑它。页面不直接读写文件，不把临时输入当作已保存状态。

## 编辑规则

新增、删除和编辑最终都走“整份替换”。服务端先归一化和去重，成功后返回真正持久化的用户词列表。空白或归一化后为空的词拒绝整次替换，文件保持不变；重复词和与内置词同形的用户词不会写入。

前端可以即时提示无效输入和重复，但服务端词库引擎是唯一判据。前端的归一化镜像仅用于预检，并由一致性守卫约束；不能成为另一套规范。写入采用原子替换，成功后引擎按文件变化热加载，无需重启。

整份保存保留文件开头连续的注释和空行，方便维护者保留文件说明；首个词条之后的注释不保证保留。页面不应承诺它能保存任意手写文件排版。

## 导入与导出

导入接受一组词并与已有用户词合并。空词、重复词和内置同形词计入跳过数量，不视为业务错误；`dryRun` 只返回将新增和跳过的数量，绝不修改文件。

导出只导出用户词，每词一行，不复制内置词或服务端词。导入文件忽略空行和以 `#` 起始的注释；导入后必须重新读取并显示最终结果，而不是假定每个输入都写入成功。

## 验证

- 缺失用户词文件显示空态且不创建文件；用户手工编辑后重开面板能读到实际内容。
- 保存、删除和导入后，页面展示持久化后的词表，词库引擎无需重启即可生效。
- 无效词不改变文件；预览不写盘；导入不会覆盖已有用户词；头部说明保留的边界明确。
- 内置词与服务端词均不可在页面编辑，前端预检与服务端归一化结论一致。
