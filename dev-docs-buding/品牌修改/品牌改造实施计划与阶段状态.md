## 1. 目标与边界

把用户可见产品身份统一为中文 **布丁盒子**、英文 **Pudding Box**，并让 Web、Desktop、Mobile、Relay、Landing 与 Windows 安装器共享可修改的品牌资料和图标资产。

## 2. 文案优化方案

### 原则

1. 先说明价值，再说明能力：首屏表达“一个工作台”，再介绍工具、任务和智能代理。
2. 中文界面使用“布丁盒子”，英文界面使用“Pudding Box”；内部兼容命令 `octo` 不作为用户可见产品名。
3. 欢迎、通知和设置使用短句；长说明只用于 About、落地页和隐私页面。
4. 不使用“绝对安全”“永不上传”等无法证明的承诺。
5. `zh-CN` 与 `en-US` 是主文案；其他语言缺少完整翻译时回退英文，不拼接中英文碎片。

### 当前采用的可替换 Mock 文案

| 场景 | 中文 | English |
|---|---|---|
| 定位 | 智能代理工作台 | Agent workspace |
| 标语 | 让本地工具、任务与智能代理，在一个工作台里协作。 | One workspace for local tools, tasks, and agents. |
| 长描述 | 布丁盒子是一套面向个人和团队的智能代理工作台，用于连接本地工具、管理任务，并在 Web、桌面和移动端之间保持连续的工作体验。 | Pudding Box is an agent workspace for individuals and teams to connect local tools, manage tasks, and keep work connected across web, desktop, and mobile. |

| 本地数据提示 | 你的工作数据默认保存在本地。 | Your work data is stored locally by default. |

这些资料均位于 `branding/brand.json`；真实主体、域名、邮箱、法律页面和商标资产到位后只修改主配置及正式 Logo，不直接改各端副本。

## 4. 当前已验证结果

2026-09-04 在本机 Windows x64、AMD Ryzen 9 5900X 上，以官方安装的 `C:\Program Files\Go\bin\go.exe`（Go 1.27.0、`windows/amd64`）重新完成：根 Go 测试和构建、Relay 测试、Desktop 嵌套模块测试，以及携带目标 amd64 `rg` 嵌入输入的 Windows Desktop 链接。此前的 `TestCompressImageData_KeepsSmaller` 依赖特定 Go JPEG 编码器的字节大小，在 Go 1.27 下稳定失败；已将其夹具改为跨支持 Go 图像编码器均稳定的 2000×1 PNG，产品压缩逻辑未改变，根模块全量测试已重新通过。

Web 的 50 个测试文件 / 666 项测试与生产构建、Mobile 的类型检查与 19 项测试、图标生成器、品牌同步测试、Inno Setup 6.7.3 安装器编译已在本轮自动化验证中保留为通过证据。`staging` 是临时验证目录，当前不保留安装器产物；需要重新生成时严格按《本地编译、打包与人工验收手册》第 4 节执行。

官方 x64 Go 已安装，但系统 PATH 仍可能优先命中旧的 `C:\Program Files (x86)\Go\bin`。管理员 PATH 修复与当前安全替代方案均在手册第 1 节；仓库、脚本和 CI 中没有持久化 `GOARCH` 设置。
